## IO

В этом пакете собраны небольшие утилиты для сохранения артефактов пайплайна:

- дампы эмбеддингов (для дебага/повторного использования);
- финальный submission CSV.

Пакет намеренно минималистичный: он не содержит бизнес-логики пайплайна
(нормализацию, удаление self-index и т.п.). Он только сериализует уже готовые
результаты.

### embeddings.py

Функции для сохранения матрицы эмбеддингов.

- `save_embeddings_npz(path, filepaths, embeddings)` - сохраняет сжатый ``.npz``
  с массивами:
  - `filepaths` (строки, длина N)
  - `embeddings` (float32, форма `[N, D]`)

### submission.py

Функции для записи submission файла.

- `write_submission_csv(path, filepaths, neighbors)` - пишет CSV с колонками
  `filepath` и `neighbours`, где `neighbours` - это comma-separated список
  индексов соседей.

### Как расширять

Если понадобится другой формат (например parquet/jsonl) - добавляйте новый модуль
в этот пакет и придерживайтесь принципа: **I/O только пишет/читает данные, не
меняя их смысл**.
