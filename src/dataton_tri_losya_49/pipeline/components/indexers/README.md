## Indexers

Индексатор отвечает за построение индекса эмбеддингов и поиск ближайших соседей для каждого объекта.

В нашем пайплайне энкодер строит эмбеддинги, а индексатор принимает матрицу эмбеддингов и возвращает
матрицу индексов `top-k` ближайших соседей для каждого объекта (без self-index).

### FaissInnerProductIndexer (faiss_ip.py)

Файл содержит реализацию KNN-поиска на основе `faiss.IndexFlatIP` с косинусным сходством:

- перед добавлением в индекс все эмбеддинги L2-нормализуются, что превращает inner product в косинусное сходство;
- поиск выполняется с `topk + 1` соседями, после чего self-index (объект сам себе сосед) сдвигается в конец и исключается из результата;
- индексатор stateless: каждый вызов `neighbors` строит новый FAISS-индекс с нуля, что упрощает API и гарантирует воспроизводимость.

API:

- `FaissInnerProductIndexer.neighbors(embeddings, topk) -> np.ndarray` — возвращает int64-массив формы `[N, topk]`.

Вспомогательная функция:

- `_l2_normalize_rows(x, eps)` — нормализует строки матрицы к единичной L2-норме.

### Как добавить новый индексатор

1) Создайте новый файл в этом каталоге (например `annoy_indexer.py`, `hnsw_indexer.py`).
2) Реализуйте интерфейс `Indexer` из `src/dataton_tri_losya_49/pipeline/interfaces.py`:
   метод `neighbors(embeddings, topk) -> np.ndarray` должен возвращать int64-массив формы `[N, topk]` без self-index.
3) Экспортируйте класс в `indexers/__init__.py`.
4) Подключите новый индексатор в фабрике `make_indexer()` в `pipeline/runner.py` и расширьте валидацию в `pipeline/config.py`.
